# まもるノート

マルチデバイス対応のフォーカシング用キャンバスノートです。ブラウザのIndexedDBに保存し、初回読込後はオフラインで利用できます。

## 起動

```bash
npm install
npm run dev
```

## セキュリティ方針
データは端末内のみです。ブラウザのデータ削除や端末の初期化でデータが消える場合があります。バックアップには暗号化ファイルを使用します（Phase2で完全実装）。

外部通信、解析、トラッキングは行いません。
